Tecnologías: Python, Flask, Streamlit, Machine Learning (Scikit-learn)

LIBRERÍAS NECESARIAS Y SU PROPÓSITO

pandas
Permite leer, limpiar y manipular el dataset (CSV).
Se usa para preparar los datos antes del entrenamiento.

Importación:
import pandas as pd

numpy
Manejo de arreglos numéricos, cálculos y operaciones matemáticas.

Importación:
import numpy as np

scikit-learn (sklearn)
Librería principal de Machine Learning.
Se utiliza para:

train_test_split (división de datos)
StandardScaler (escalado de variables)
RandomForestClassifier (modelo principal)
Métricas: accuracy_score, confusion_matrix, classification_report

Importaciones:
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

joblib
Guarda y carga el modelo entrenado (.sav)

Importación:
import joblib

flask
Framework backend para crear la API REST.
Recibe datos del usuario y devuelve predicciones en JSON.

Importación:
from flask import Flask, request, jsonify

flask-cors
Permite que Streamlit se conecte al backend sin errores CORS.

Importación:
from flask_cors import CORS

requests
Usado por Streamlit para enviar datos al backend.

Importación:
import requests

streamlit
Construye la interfaz visual del proyecto.

Importación:
import streamlit as st

pathlib

Manejo seguro de rutas del sistema operativo.
Importación:
from pathlib import Path


INSTALACIÓN GENERAL

Crear entorno virtual:
python -m venv venv


Activar entorno virtual:
venv\Scripts\activate

Instalar librerías necesarias:
pip install pandas numpy scikit-learn joblib flask flask-cors requests streamlit

RESUMEN DEL USO EN EL PROYECTO

modelos/entrenar.py
Usa: pandas, numpy, sklearn, joblib, pathlib
Función: Entrena el modelo, calcula métricas y guarda modelo .sav

backend/app.py
Usa: flask, flask-cors, joblib, numpy
Función: API REST que recibe datos y devuelve predicción en JSON

interfaz/interfaz.py
Usa: streamlit, requests
Función: Interfaz gráfica con estilo médico conectada al backend
